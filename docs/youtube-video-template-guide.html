PbootCMS 模板直接嵌入油管视频（不进数据库）

视频不写进 PbootCMS 数据库，只在模板里用 iframe / 一段 JS 把 YouTube 视频调出来播放。

1原理：油管视频就是一个 iframe 地址

YouTube 对所有视频都提供了「嵌入地址」，直接贴在模板里就能播，完全不经过 PbootCMS 数据库。

你要嵌入的东西iframe 的 src 写法
单个视频 https://www.youtube.com/embed/视频ID
整个播放列表 https://www.youtube.com/embed/videoseries?list=播放列表ID
结论：你只需要「视频 ID」或「播放列表 ID」，把它们填进模板的 iframe 里即可。模板里可以完全不用 {pboot:list}、[list:ext_vv] 这些数据库标签。

2方法一：直接内嵌单个视频

最简单。把视频 ID 填进 src。

{include file=comm/top.html}

<!-- 16:9 视频播放器，src 里就是 YouTube 视频 ID -->
<div style="position:relative;max-width:960px;margin:0 auto;padding-top:56.25%;">
  <iframe
    src="https://www.youtube.com/embed/DUOiRDZcIA4"
    style="position:absolute;top:0;left:0;width:100%;height:100%;"
    frameborder="0"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
    allowfullscreen></iframe>
</div>

{include file=comm/foot.html}

3方法二：直接内嵌整个播放列表（最省事）

如果一个分类页想放一整个播放列表，用 videoseries?list=播放列表ID，YouTube 自带的播放器会带侧边列表、上一首下一首，零代码。

{include file=comm/top.html}

<div style="position:relative;max-width:960px;margin:0 auto;padding-top:56.25%;">
  <iframe
    src="https://www.youtube.com/embed/videoseries?list=PLfhPbl0MgZYJsjQ2Gt-e-jd3CaMSrX6Tl"
    style="position:absolute;top:0;left:0;width:100%;height:100%;"
    frameborder="0"
    allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
    allowfullscreen></iframe>
</div>

{include file=comm/foot.html}
适用场景：你的频道每个「播放列表」正好对应一个栏目页，一个页面放一个 iframe 就完事。缺点：样式是 YouTube 原生播放器，没法自定义卡片外观。

4方法三：模板里写一个视频清单（JS 数组，卡片+点击播放）推荐

在模板里维护一个视频数组（标题 + 视频 ID），用一段 JS 渲染成卡片，点击卡片在本页播放。能完全复刻之前那种卡片墙体验，但数据只存在模板文件里，不进数据库。

<!-- 只要在这里加一行视频，不用动数据库 -->
var videos = [
  { title: "380-8 挖掘机演示", id: "DUOiRDZcIA4" },
  { title: "另一条视频标题", id: "xxxxxxxxxxx" },
  { title: "再一条",          id: "yyyyyyyyyyy" }
];
封面图是自动生成的：每条视频的缩略图用 https://i.ytimg.com/vi/视频ID/hqdefault.jpg（YouTube 固定规则，视频 ID 拼上去即可，无需上传图片）。想更清晰可换成 maxresdefault.jpg。

5可直接用的完整模板（方法三）

复制下面整段到你的 videolist.html（或新建的模板文件），改一下开头的 videos 数组即可。

{include file=comm/top.html}

<!-- ============ 播放器（点击卡片后出现在这里） ============ -->
<div id="playerWrap" style="display:none;max-width:960px;margin:16px auto;">
  <div style="position:relative;padding-top:56.25%;background:#000;border-radius:10px;overflow:hidden;">
    <iframe id="player" src="" frameborder="0"
      allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
      allowfullscreen style="position:absolute;inset:0;width:100%;height:100%;"></iframe>
  </div>
  <p id="playerTitle" style="text-align:center;color:#666;margin-top:10px;"></p>
</div>

<!-- ============ 卡片墙 ============ -->
<div id="grid" style="display:grid;grid-template-columns:repeat(auto-fill,minmax(280px,1fr));gap:16px;padding:16px;"></div>

{include file=comm/foot.html}

<script>
(function () {
  /* 只在这里维护视频清单，不需要数据库 */
  var videos = [
    { title: "380-8 挖掘机演示", id: "DUOiRDZcIA4" },
    { title: "另一条视频标题", id: "xxxxxxxxxxx" },
    { title: "再一条",          id: "yyyyyyyyyyy" }
  ];

  var grid = document.getElementById('grid');
  var wrap = document.getElementById('playerWrap');
  var player = document.getElementById('player');
  var title = document.getElementById('playerTitle');

  videos.forEach(function (v) {
    var card = document.createElement('button');
    card.type = 'button';
    card.setAttribute('data-id', v.id);
    card.setAttribute('data-title', v.title);
    card.style.cssText =
      'display:block;width:100%;padding:0;border:0;border-radius:10px;overflow:hidden;' +
      'background:#fff;text-align:left;cursor:pointer;box-shadow:0 2px 10px rgba(0,0,0,.08);';
    card.innerHTML =
      '<div style="position:relative;padding-top:56.25%;background:#000;">' +
        '<img src="https://i.ytimg.com/vi/' + v.id + '/hqdefault.jpg" alt="' + v.title + '" ' +
             'loading="lazy" style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover;" />' +
        '<span style="position:absolute;inset:0;display:flex;align-items:center;justify-content:center;">' +
          '<span style="width:52px;height:52px;background:rgba(220,38,38,.9);border-radius:50%;color:#fff;' +
            'display:flex;align-items:center;justify-content:center;">▶</span>' +
        '</span>' +
      '</div>' +
      '<div style="padding:12px 14px;">' +
        '<h3 style="margin:0;font-size:15px;color:#333;overflow:hidden;text-overflow:ellipsis;white-space:nowrap;">' + v.title + '</h3>' +
      '</div>';

    card.addEventListener('click', function () {
      var id = card.getAttribute('data-id');
      player.src = 'https://www.youtube.com/embed/' + id + '?autoplay=1';
      title.textContent = card.getAttribute('data-title') || '';
      wrap.style.display = 'block';
      wrap.scrollIntoView({ behavior: 'smooth', block: 'center' });
    });
    grid.appendChild(card);
  });
})();
</script>

6怎么拿到「视频 ID / 播放列表 ID」

你手上的链接ID 是哪一段
https://www.youtube.com/watch?v=DUOiRDZcIA4视频 ID = DUOiRDZcIA4
https://youtu.be/DUOiRDZcIA4视频 ID = DUOiRDZcIA4
https://www.youtube.com/playlist?list=PLfhPbl0MgZYJsjQ2Gt-e-jd3CaMSrX6Tl播放列表 ID = PLfhPbl0MgZYJsjQ2Gt-e-jd3CaMSrX6Tl

7常见问题

  • 需要在后台建栏目吗？—— 需要一个空栏目来承载页面，把它的「列表模板」指向这个 videolist.html（或你新建的模板名）即可。视频内容本身不用在后台一条条添加。
  • 封面不显示 / 视频加载慢？—— 视频和封面都来自 YouTube 外链，国内网络可能打不开，属正常现象；若面向国内用户需另想办法（如用代理、或换 bilibili 等平台）。
  • 能自动播放吗？—— 在 src 后加 ?autoplay=1（注意有些浏览器会拦截有声自动播放，需用户先点击一次）。
  • 想一个页面放好几个播放列表？—— 每个播放列表写一个 iframe，src 用 videoseries?list=播放列表ID 即可。
  • 视频 ID 列表很长，写进模板会不会乱？—— 可以单独建一个 .js 文件放 videos 数组，模板里 <script src="..."> 引入，维护更方便。

模板文件位置：template/<语言>/html/videolist.html（或复制一份另起名，再在栏目里指定该模板）。

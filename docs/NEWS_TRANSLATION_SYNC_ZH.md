# 新闻翻译状态与范围同步

新闻列表与产品列表使用相同的翻译完成度和同步预检流程。

- 翻译状态：未翻译、部分未翻译、已全部翻译；统计网站当前配置的外语，包括印尼、土耳其、越南语。
- 悬停状态可看到缺少的语言和字段；可以筛选未完成的新闻。
- 完成度检查已保存的标题、正文，以及中文源稿存在的 SEO 字段。它不是翻译语义质量评分。
- “一键同步到 PB”选择中文新闻栏目，范围包含子栏目，覆盖该范围全部配置语言。
- 同步前显示可写入的版本、内容不完整而跳过的版本、栏目或 URL 冲突。
- 不用中文内容填充缺失的外语版本。栏目缺失、多个匹配或 URL 冲突时禁止同步，不使用旧的硬编码栏目兜底。
- 执行前备份 PB 数据库；仅新增或更新，不删除范围外的 PB 新闻。

已有“覆盖 PB 当前范围”属于原来的当前语言操作，保留原确认流程；跨语言发布使用新的“一键同步到 PB”。

## 新闻缩略图

新闻与产品使用同一套500×400 JPEG缩略图处理，按比例缩放、居中补白，不裁切、不拉伸，原图保持不变。

- **文件夹批量导入**：每篇新闻一个文件夹。扫描只显示“待生成”，不写文件；确认导入时，如果没有 `0.jpg`，从 `1.jpg` 生成并放回该新闻文件夹。已有 `0.jpg`（含大写扩展名）直接使用，不覆盖、不改尺寸。兼容编号 `1` 的 PNG、WebP、JPEG。
- 当前网站 `static` 内的新闻资料直接引用原目录地址，不额外复制一套图片。外部资料先在源新闻目录生成 `0.jpg`，再按原导入规则复制到当前网站。
- 缺少编号 `1` 时不拿正文图随意生成，保留缺图提示及原有回退规则。损坏源图会报告该篇导入失败，其他新闻继续；同栏目重复标题仍跳过。
- **手动上传**：新建新闻先选择中文新闻栏目、填写中文标题。优先定位网站 `static` 内同标题的新闻目录；没有对应目录时，创建 `static/codex/news-images/栏目ID/新闻标题/`。
- 编辑已有新闻时使用该新闻在当前站点已保存的中文标题定位目录。同名目录无法唯一确认时，先在缩略图地址框填入目标目录中已有图片的地址再上传。
- 手动上传生成 `thumbnail-随机编号.jpg`，不会覆盖 `0.jpg` 或原缩略图；保存新闻后更新引用，所有语言共用这份缩略图。仅上传不会发布 PB 新闻，仍使用原有同步按钮发布。
- 新闻正文图片仍走原上传接口，尺寸不变；手动填写已有图片地址也不会自动修改文件。不添加 AI 图片 ALT 功能。
- 上传源文件上限5MB；文件夹源图上限30MB、4000万像素。目录必须可写。宝塔部署沿用产品缩略图要求：服务器重新安装依赖，不能复制 Windows 的 `node_modules`，Node 服务用户需要该网站图片目录的读写权限。

验证使用临时目录和合成图片，不改动现有新闻、产品或 PB 数据。

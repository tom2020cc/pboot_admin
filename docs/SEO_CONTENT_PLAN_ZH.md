# SEO 内容计划

## 已确认的产品方向

同一管理后台、同一代码仓库、独立后台任务进程。每个网站有自己的行业、关键词、素材、写作要求、模型、中文栏目和发布计划。共享模型凭据不代表共享网站资料。

默认关闭网站总开关，全局默认暂停。关闭后不得新建自动任务或继续发布；编辑、审核草稿不受影响。重新开启不补发停用期间积压的文章。

## 第一版交付范围

- 每站一个独立计划，可配置写作模型、行业、品牌、关键词、资料源、生成间隔和每日生成上限。
- 通过 HTTPS RSS/Atom 订阅源发现匹配关键词的标题，保留来源和日期，按站点去重。也可手工录入经过确认的事实资料。
- 采集标题只进入待核实素材库；只有人工确认过的资料才会被用于生成。没有合格资料时不凑数生成。
- 独立 worker 领取带站点、模型和素材快照的任务，执行采集或 AI 写作，通过专用受认证接口回传。worker 不打开后台数据库或 PB 数据库。
- 草稿独立保存，支持修改、检查、审核排期和撤销排期。只向当前网站中文新闻栏目发布单篇文章，不调用全站覆盖接口。
- 所有 AI 输出按不可信内容处理，清理 HTML，不执行脚本，不自动补图片 ALT，不自动获取第三方图片。事实和相似度检查仅辅助人工审核，不承诺原创率或排名。
- 任务持久化、领取锁、租约、心跳和异常记录；不盲目重试已开始的付费请求或不确定的发布结果。失败需人工重试，模型不自动降级。

## 第二轮完善（2026-09-10）

- 每站可独立开启 Brave Search 关键词搜索，默认关闭。每次采集最多轮换搜索 3 个关键词，查询同时包含本站行业；每个查询最多读取 10 条结果，只保留匹配关键词的标题与链接，不提取搜索摘要当作事实。
- 采集任务每日上限独立于写作任务上限，默认每站每天 4 次，按 UTC 统计；手动采集和自动采集共同计数，失败也计数。同一任务的人工重试不新增任务计数，最多三次尝试，可能再次产生费用。搜索次数不是费用账单。
- RSS 与搜索支持部分成功：某个来源失败时保留其他成功结果，任务显示失败代码；所有来源都失败才标记采集失败。搜索采集同样进入待核实素材库，不直接写作或发布。
- 草稿审核新增本地质量报告：正文字符数、小标题、本站关键词覆盖、重复标题和正文相似度。对比本站最近 200 篇新闻的中文版本及最近 200 条相关写作任务，排除当前草稿及其关联新闻；不读取其他网站资料。
- 与对比范围内既有新闻、已排期或已发布任务标题重复时禁止排期；正文相似度、篇幅和结构是人工复核提示，不作为自动删除或全自动拒稿依据。相似度是本地字符片段比较，不是全网查重，也不证明原创率。
- 修改正文后需重新检查；排期和实际发布前服务端都会重新验证，不依赖浏览器上的绿灯。
- 页面显示本站今日写作/采集用量、进程凭据配置状态、最近心跳与搜索接口配置状态。429 模型/搜索错误显示明确原因，不自动切换模型、重试付费请求。
- 新增只读 worker 检查与 Windows 独立启动入口，不改变任何网站开关。旧计划缺少新字段时只在读取时补默认值，不批量改写历史计划或新闻。

## 后续迭代

多计划、其他搜索引擎接口、按模型价格精确核算费用、Search Console 效果反馈、历史版本一键回滚。在这些项目完成前，不将其标记为已有功能。图片采集、生成和 ALT 不属于本模块范围。

## 第三轮：纯文字与 DeepSeek Skill（2026-09-10）

- 新计划的搜索来源默认 DeepSeek，关键词搜索仍默认关闭。已有启用 Brave 的旧配置继续按 Brave 解释，不静默迁移用户的选择；在页面选择 DeepSeek 并保存即可切换。RSS 无需任何搜索密钥。
- 搜索来源、研究模型、写作模型分别选择。DeepSeek 研究使用固定的官方 `/responses` 与 `web_search`，提供 Flash/Pro 选项；不把普通聊天生成的文字假称搜索结果。当前没有 Tavily 或智谱搜索适配器。
- DeepSeek 输出必须成功完成搜索调用，且来源 URL 必须与响应中的 `url_citation` 对得上。无法核实来源、返回截断或格式错误即失败，不静默回退到模型记忆，不自动重试。空结果不凑数生成。
- 只保存匹配主题的标题、真实来源、简短文字研究笔记和有依据的日期；每来源笔记上限 600 字符，每次研究最多 5 个来源。笔记一律待核实。RSS 附带的文字摘要也可进入待核实笔记，没有摘要仍只录入选题。
- 不下载图片、不生成图片或 ALT、不复制第三方整篇文章。不自动覆盖已入库素材及人工编辑的笔记；同一 URL 已入库时跳过。保存来源与摘要仍需确认服务条款及内容使用权。
- 每站新增已核实文字知识、明确勾选的参考产品（最多 10 个）。后台重新校验产品归属，只给写作模型发送中文文字及共享产品参数，不包含价格、缩略图、大图、轮播或视频字段。搜索不接收产品事实或草稿，仅接收本站行业、关键词和已有文章标题。
- 五组规则位于 `tools/seo-content-worker/skills/`：选题、研究、写作、复核、旧文更新。它们是本项目加载的编辑规则，不是模型自动安装或免费联网的插件。后端生成内容哈希版本，连同规则全文一起固化在任务快照，worker 实际加载快照规则；后续修改规则不改变旧任务。页面 SEO Skill 可查看当前规则，写作要求可增加本站补充要求。
- 每日搜索请求上限按 UTC 统计，并在排队时预留。每个采集任务最多 3 个关键词请求，手动重试也占当天请求额度，取消不退还预留额度。DeepSeek 一个 Responses 请求可能在服务商内部执行多轮工具调用；本模块限制的是外部 API 请求数，不声称能限制内部搜索次数或精确限制费用。
- 单次模型输出上限为 1,000 到 8,000 Token，应用于研究和写作；输入内容另行计费，失败也可能计费。累计显示供应商返回的用量，不以它代替服务商账单。没有网络请求或使用免费额度并不保证模型写作免费。
- “文章库与更新”显示本站最近 200 篇有效中文新闻。选择一篇同栏目旧文及已核实的新素材，生成独立更新草稿；不会在生成时修改新闻。审核页显示更新前后文字、原 URL 与 Skill 版本，历史记录按文章和站点查询。
- 更新保留新闻 ID、URL、原始创建日期、缩略图、原有普通图片及已有其他语言内容。旧文必须已有稳定的 URL 名称；更新 PB 已有新闻时保留 PB 原发布日期，首次补建 PB 副本时采用后台原始创建日期。若 PB 地址重复或对应其他栏目则停止更新，普通新闻同步行为不变。
- 原图在模型输入中用有序占位符替代，审核检查不能丢失、重复或乱序，发布时恢复原有安全图片标签。含视频、iframe、picture、SVG、canvas 等复杂正文不自动更新，回到原新闻编辑页维护；不猜测其布局或删除媒体。
- 原文内容和元数据生成摘要指纹，排期及发布前重查，数据库更新使用原字段匹配避免覆盖并发修改；PB 写入前再次检查。原文变化或素材撤销核实会阻止发布。无正文实质变化时拒绝仅改标题或日期的更新。可撤销旧草稿后基于新原文重新生成。
- 同一篇文章的已发布历史版本不作为自己的重复标题；其他文章的重复标题仍然拦截。
- 历史记录保留更新前文字和最终草稿，可查看对照；暂不提供一键回滚。更新不自动重翻译外文，也不自动恢复失败的 PB 同步；发布不确定时需要人工核实。

## 数据与安全

每次管理操作要求显式站点 ID，并校验站点启用状态和栏目归属。任务固定站点，不能使用“当前默认网站”回退。素材、草稿、任务查询均带 siteId。

`sql.js` 模式只允许一个主后端进程写库。worker 只能使用接口。PB 发布前重新检查开关和栏目，对磁盘原始文件做变化检测，避免覆盖检测到的并发修改。

HTTPS 采集限制端口、响应大小、超时和可用公网地址，禁止内网/回环/云元数据地址；连接固定到经验证的解析地址，禁止自动重定向。禁止 XML DTD/实体声明。来源仅作为资料，不是指令。

## 内容准则

以自有事实、可信来源和实际选型价值为基础，不搬运整篇文章、不编造案例、不重复堆词。公司新闻与行业知识分开。人工确认事实后再发布。

参考：[Google AI 内容指南](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content)、[内容质量指南](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)。

## 使用入口

后台“内容管理 → SEO 内容计划”，地址 `/#/seo-content`。每个网站初次进入均未启用。

1. 选择网站，填写行业、品牌、关键词和中文新闻栏目，选择已配置的写作模型，保存配置。
2. 可选填写 HTTPS RSS/Atom 地址。联网文字研究选择 DeepSeek、研究模型并启用关键词搜索；写作模型可以独立选择。参考产品和本站事实资料仅用于写作。保存配置后开启本站开关并解除全局暂停。
3. 手动新增自有资料，或在采集条目中补充核实过的事实摘要，确认资料使用权后勾选已核实。
4. 点击“研究文字素材”收集待核实的文字资料。确认素材后点击“生成草稿”，或者等待下一次计划执行。旧文更新则在“文章库与更新”选择目标文章及更新依据。
5. 在“草稿与任务”编辑、查看预览，核实参数、事实和来源后选择将来时间，审核排期。
6. 发布只调用当前网站单篇中文新闻同步。只有明确选择旧文并审核排期才会更新该文章，其他文章、语言及网站不自动改动。

每日上限按 UTC 自然日统计新建写作任务，失败任务也计数；同一任务最多尝试三次。间隔为经过的小时数，不依赖服务器时区。发布时间在浏览器本地时区输入、以 UTC 保存；界面显示本地时间。模型消费 tokens 是供应商回传值，失败请求可能计费但不返回用量，不能当作准确账单。

修改计划只影响后续新任务；已有任务保留创建时的模型、栏目和事实资料快照，重试也不悄悄更换模型。第一版暂不提供单篇切换模型重写按钮。

当前页面显示最近 500 个素材和 200 个任务。后台计划可以继续使用本站更早的已核实素材。暂无删除资料、全站改写或自动翻译发布。

## 关键词搜索配置

DeepSeek：在 `backend/.env` 配置 `DEEPSEEK_API_KEY`，或复用现有模型配置里的 DeepSeek 密钥，重启主后端和 worker。搜索来源选择 DeepSeek，研究模型选择 V4 Flash 或 Pro，写作模型独立选择。Brave 不再是启用计划的必要条件。官方能力参考 [Responses API](https://api-docs.deepseek.com/guides/responses_api/)；必须对真实账号的小量请求、工具调用和账单进行上线验收，本轮只使用模拟请求测试。

Brave 可选：在 `backend/.env` 设置 `BRAVE_SEARCH_API_KEY` 后重启主后端和 worker。不要在聊天、前端配置、GitHub 或素材备注中填写密钥。主后端只向前端返回是否配置；凭据不进入任务快照、日志或网页。

Brave Search 是独立的第三方搜索服务，需自行开通相应接口。启用后会发送当前网站的行业和关键词，不发送产品数据库、草稿或完整事实资料。RSS 不依赖此密钥。接口接入参考 [Brave Web Search 官方文档](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started) 与 [认证说明](https://api-dashboard.search.brave.com/documentation/guides/authentication)。

注意：[Brave 官方 FAQ](https://api-dashboard.search.brave.com/documentation/resources/help-feedback) 对搜索数据留存有限制。当前模块需要保存来源标题及链接，使用前须确认你的方案允许此用途；没有相应授权请关闭 Brave，改用允许该用途的来源。

## 本地与宝塔启动

要求 Node.js >= 22.12.0。安装依赖并构建：

```sh
cd backend
pnpm install --frozen-lockfile
pnpm run build
cd ../frontend
pnpm install --frozen-lockfile
pnpm run build
cd ..
node tools/seo-content-worker/setup.cjs
```

setup 只在 `backend/.env` 中生成随机工作进程凭据，不输出密钥、不启用网站。凭据由主服务和 worker 共用，请限制 `.env` 的文件权限。更换机器后应重新生成；设置好环境后先重启主后端，再启动 worker：

```sh
node tools/seo-content-worker/index.cjs
```

先执行只读诊断，不领取任务、不调用模型、不发布文章：

```sh
node tools/seo-content-worker/index.cjs --check
```

Windows 可运行 `08-start-seo-content.cmd`：检查主后端认证后后台启动 worker，日志位于 `logs/seo-content-worker.out.log` 和 `logs/seo-content-worker.err.log`；检测到通过该入口运行的进程则不重复启动。不要同时用不同入口手工启动多个 worker。只检查、不启动可执行 `powershell -NoProfile -File tools/start-seo-content.ps1 -CheckOnly`。启动进程不等于启用任务，网站总开关与全局开关仍需单独开启。

默认连接 `http://127.0.0.1:5108`，随 `BACKEND_PORT` 调整。不同机器部署时显式设置 `SEO_WORKER_API_URL`，必须 HTTPS。主服务与 worker 使用相同的 `SEO_WORKER_TOKEN`，至少 32 字符。写作模型密钥复用后端环境变量或 `tools/seo_publish_tool/ai.config.json`，不通过任务接口传递。

宝塔使用进程守护管理该 worker，或已有 PM2 时：

```sh
pm2 start deploy/seo-content.ecosystem.cjs
pm2 save
```

主后端在 sql.js 模式必须单实例，worker 配置也是单实例。按服务器环境配置开机启动；可参考 [PM2 进程配置](https://pm2.keymetrics.io/docs/usage/application-declaration/)。公网反向代理应禁止访问 `/seo-worker/`，本机 worker 直连内网后端端口；防火墙不要开放该内部端口。

部署包必须保留整个 `tools/seo-content-worker/`，包括 `skills/*.md`；缺少编辑规则时后端拒绝创建任务。需要允许服务器访问 `api.deepseek.com:443` 及配置的 RSS 公网 HTTPS 来源，不需要开放额外图片服务。本地及宝塔均使用相对项目路径解析规则，不依赖 Windows 盘符。

关闭本站/全局开关时，待执行任务暂停、已排期文章回到草稿，发布中的任务取消租约并标为需核实，写入 PB 前再次检查。已进行的外部请求可能产生费用，关闭开关不代表退费，也不删除已发布内容。

停机期间错过超过一小时的发布回到草稿，不自动集中补发。租约过期的写作任务标为失败，发布任务标为“需核实结果”，不自动重试。请通过任务关联的新闻记录检查 PB 并手工同步；第一版不自动判定未知发布结果或重复创建新闻。

## 验证

```sh
cd backend
pnpm test -- --runInBand
cd ..
node --test tools/seo-content-worker/worker.test.cjs tools/seo-content-worker/research.test.cjs
node tools/verify-seo-content.cjs
```

单元/流程测试使用内存 SQLite，AI 和 PB 同步均模拟。浏览器测试拦截所有后端请求，覆盖素材确认、草稿保存、排期、跨网站切换及桌面/手机布局。真实 worker 仅以默认关闭状态检查认证与空队列；未使用付费模型或真实发布文章。服务器宝塔实机部署仍需在目标服务器验收。

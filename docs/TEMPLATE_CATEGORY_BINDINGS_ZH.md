# 模板栏目绑定与产品列表

## 后台入口

系统管理 → 模板栏目绑定。操作跟随顶部选中的当前网站，仅处理该网站 `template/cn`、`template/en` 下的 HTML 模板。

1. 首次进入会读取模板里的固定栏目编码，以及项目已同步的中文、英文栏目。能明确匹配的会自动选中，不会立即修改模板。
2. 需要更换栏目时，在中文、英文列分别选择栏目。下拉末尾方括号内是 PB 栏目编码，不是项目数据库 ID。
3. “保存绑定”只保存对应关系，不改网站模板。
4. “预览更新”显示文件、行号和编码的前后变化。确认“备份并更新模板”才写入模板。
5. 如果提示 PB 栏目不存在，先在菜单管理同步对应语言栏目，再重新读取、预览。网站开启模板缓存时，更新后在 PB 后台清理缓存。

## 更新范围与保护

- 支持原生 `pboot:nav` 的固定 `parent`、`scode`，以及 `pboot:sort/list/content` 的固定 `scode`；支持逗号分隔编码和编号标签。
- 不更改栏目名称、产品内容、图片地址、样式、PB 数据库或核心程序。
- 动态 `{sort:scode}`、`{sort:pcode}`、`{sort:tcode}` 保持原样。它们已经随当前栏目自动关联，不需要逐个绑定。
- 共用模板和写死的 URL 不自动改写。共用模板中推荐使用上述动态标签。
- 相同编码在同一语言中的所有固定引用作为一组更新；不会猜测中英文编码差值。无法确认的栏目可以留空，保持原编码。
- 模板或绑定配置在预览后被修改，更新会停止并要求重新预览。两个来源不能合并成同一个目标编码。
- 更新前在当前站点管理目录 `backups/template-bindings/<批次>` 保存原文件和清单，路径在成功提示中显示。写入中途出错会尝试回退本次修改，外部新修改不会被强行覆盖。
- `state/template-bindings.json` 保存绑定。移动到宝塔时同时迁移该站点管理目录，在站点管理配置新的网站根目录与 PB 数据库路径。旧的预览不能跨服务重启或跨站点使用。
- 本功能要求 PB SQLite 数据库位于所选网站真实 `data` 目录，模板为 UTF-8，拒绝符号链接和活动事务日志。不会自动安装扩展或改变服务器权限。

## 前台产品列表

cn/en 保留原站的多语言组织方式，各语言使用自己的 `productlist.html` 和公共导航、静态资源：

```text
template/cn/html/productlist.html
template/en/html/productlist.html
template/comm/product-sort.html
static/tem/css/product-list.css
static/tem/js/product-categories.js
```

- 一级页面展示子栏目；中间级展示产品分类和子栏目；末级保留上层分类及同级分类，当前分类高亮。
- 栏目名称、链接、产品和参数来自当前语言 PB 数据，不限制导航为前 10 项。
- 卡片展示所属栏目、型号、缩略图和现有钻机参数。标题、图片链接到产品详情，原生分页保留，空栏目显示空状态。
- 岩芯参数为钻探深度、取芯能力、提拔力；没有取芯能力时使用钻孔直径、回转扭矩。空参数不编造、不展示空行。
- 产品图片按原始比例自然撑高，宽度随卡片自适应，不固定图片宽高、不裁切、不拉伸。
- 此次只调整产品列表，不改产品详情图集、页头、页脚和 PB 核心程序。

发布宝塔时应同时上传以上五个文件，保留路径和文件名大小写。资源 URL 为站内相对路径，没有绑定本机盘符或 localhost。

## 回归验证

- 后端：`npm test -- --runInBand template-bindings`，在临时站点与临时数据库内测试备份、更新、回退和错误保护。
- 后台界面：`node tools/verify-template-bindings.cjs`，所有 API 被替身拦截，不更新真实模板。
- 前台：`node tools/verify-public-product-list.cjs`，只读取本地 PB 数据并浏览页面，检查中英文导航、图片比例、空状态、链接及移动端布局。
- 两个浏览器脚本支持 `PLAYWRIGHT_MODULE` 指定 Playwright 安装位置；前台脚本支持 `SHANBO_RIG_ROOT`、`SHANBO_RIG_URL`、`SHANBO_RIG_DB`。

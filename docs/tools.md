# Standalone Tools

## FTP publish tool

Path:

```text
tools/ftp_publish_tool
```

Start:

```text
start.cmd
```

URL:

```text
http://localhost:5389
```

Use it to upload the local PbootCMS database, images, sitemap, robots file, and IndexNow key file to hosting by FTP.

## SEO publish tool

Path:

```text
tools/seo_publish_tool
```

Start:

```text
start.cmd
```

URL:

```text
http://localhost:5388
```

Use it to generate sitemap and robots files, check SEO fields, and submit IndexNow URLs.

## Independent use

If you want a tool to work directly against a PbootCMS website folder, copy the tool folder into that website root and run `start.cmd` there.

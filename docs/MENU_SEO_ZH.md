# 中文栏目 SEO 与 PB 栏目同步

## 日常操作

1. 在菜单管理中选择中文，编辑对应栏目。
2. 填写栏目缩略图、大图、SEO 标题、SEO 关键字和 SEO 描述。也可以点击“AI 优化中文 SEO”生成三个 SEO 字段的草稿，检查后保存。
3. 使用“一键翻译栏目”：名称和非空 SEO 从中文翻译，图片沿用中文；已有外语 URL 不覆盖。
4. 使用“同步全部到网站”发布各语言的栏目数据。单行“同步网站”只发布该行对应栏目。

其他语言的 SEO 和图片为只读，直接修改请求也会被后端拒绝。AI 不自动保存或发布，不修改栏目名称、URL、图片，不提供图片 ALT 自动补全。

## 字段对应

| 项目字段 | PB 原生字段 |
| --- | --- |
| 栏目缩略图 `thumbnail` | `ico` |
| 栏目大图 `largeImage` | `pic` |
| SEO 标题 `seoTitle` | `title` |
| SEO 关键字 `seoKeywords` | `keywords` |
| SEO 描述 `seoDescription` | `description` |

绑定使用当前网站 + 语言 + PB 栏目编码，例如 `pboot:cn:15`，不是项目本地菜单 ID。编码在编辑页不可修改。栏目模型、列表模板、详情模板以及 PB 核心程序和数据库结构不因本功能改变。

旧项目记录的新增字段为 `null` 时，读取对应 PB 栏目作为初始值，不自动保存；主动清空后保存的空字符串表示明确清空，仅清空对应字段。旧菜单图标兼容为缩略图，不再同时写到大图。

上传到项目的图片在同步时复制到当前网站的 `static/codex/menus`；已有网站 `/static/` 地址直接使用。路径依据站点配置解析，不写死本机磁盘路径。复制失败时终止 PB 数据写入。

## 部署与验证

后端重新构建并启动后，由项目现有 TypeORM 配置添加五个本地可空文本字段。升级前备份项目数据库；不需要在 PB 增加字段。宝塔部署沿用项目现有数据库配置和站点目录配置，确保上传目录、网站静态目录及备份目录具备相应权限。

整站多语言 SEO 翻译比仅翻译名称耗时更长，页面等待上限为 30 分钟。失败时会提示错误；当前语言的完整翻译通过检查后才开始保存，前面已成功的语言可能已保存。操作期间避免重复点击、切换站点或关闭页面。

后端测试：`npm test -- --runInBand menu-seo menu.service pboot-uploaded-images`。
浏览器测试：设置 `PLAYWRIGHT_MODULE` 后运行 `node tools/verify-menu-seo.cjs`，可选 `MENU_TEST_IMAGE` 指定预览样本图片。测试所有管理 API 均为模拟响应，不调用真实 AI，也不写入真实 PB 栏目。

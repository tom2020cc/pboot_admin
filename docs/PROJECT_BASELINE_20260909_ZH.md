# 2026-09-09 开发基线

## 当前项目

集中管理多个 PbootCMS 网站，共用后台和模型配置，按站点隔离内容、栏目、资源、发布和备份。

本次基线保留当前工作区的全部功能，包括中文母版栏目关联及单栏目翻译、产品和新闻文件夹导入、缩略图处理、多语言翻译和 PB 同步、产品字段管理、模板栏目绑定、资源清理、SEO 检查和产品介绍 PDF。

## 本次备份

- 在工作区外建立带时间戳的独立备份目录，保存源码、Git 历史、本地配置、上传文件和数据库。
- 排除可重新安装的 node_modules、构建产物、旧备份、临时文件和日志。
- 逐个文件计算 SHA-256，验证副本与源文件一致。该备份含敏感配置，只保留在本机，不上传 GitHub。
- GitHub 只提交可公开的源码、示例配置、测试和文档，不提交真实配置、数据库、截图和运行状态。
- 本项目目录以外的受管 PB 网站不属于此项目备份范围；其数据库、模板和资源需另行备份。

## 下一阶段

新增按站点隔离的 SEO 内容计划。采用同一项目、独立任务进程、后端单写入者的方式。默认禁用，中文创作母版，写作模型独立选择，草稿经过审核后才可按计划发布。详细需求及实际交付范围见后续 SEO 内容计划文档。

恢复时先停止服务，将备份项目复制到独立目录，安装依赖、检查本地路径和端口后再启动。不要直接覆盖正在运行的数据库。

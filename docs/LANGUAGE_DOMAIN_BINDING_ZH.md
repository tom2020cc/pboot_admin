# 区域绑定多个域名时的语言选择

## 2026-09-24 排查结果

区域数据库中英文已设为默认，域名为 `shanbo-rig.com,www.shanbo-rig.com`。实际请求线上根路径（不附带额外查询参数）发现：

- 主域名和 www 不携带语言 Cookie：HTTP 200，英文标题，`html lang="en"`。
- 同样两个域名携带 `lg=cn`：HTTP 200，中文标题，`html lang="zh-CN"`。
- `cn.shanbo-rig.com` 无 Cookie 或携带 `lg=en`：仍正确返回中文。

本地 PB 的 `apps/common/HomeController.php` 原实现把区域 `domain` 字段整串与当前 Host 比较。逗号分隔的两个域名都不能匹配，程序便继续沿用浏览器旧语言 Cookie；仅首次访问没有 Cookie 时才使用默认英文。单域名的中文区域能匹配，因此始终覆盖旧 Cookie。

## 新网站怎样使用

1. 在本地管理后台顶部选择要操作的网站，进入“区域管理”。
2. 点击“修复并同步 PB 程序”，核对当前网站及线上 FTP 目标。
3. 只测试本地时点“只修复本地”；要一起上线时点“修复并同步到线上”。
4. 完成后打开对应域名核对语言。页面仍旧时，在 PB 后台清理缓存后刷新。

每个网站使用自己的根目录及“网站发布 → 当前网站文件同步”中保存的 FTPS 配置。没有配置时不可同步。换网络后，如果提示连接网卡不可用，请在该网站发布连接中选择当前可用网卡并保存。本次实际测试将已断开的“以太网”更改为已连接的“以太网 3”，未修改系统网卡或路由。

修复只替换已识别的 `apps/common/HomeController.php` 域名匹配代码。线上文件单独读取并修补，保留线上其它自定义代码。先上传临时文件并回读校验，再替换目标文件并再次校验。已修复则跳过；代码版本不兼容、文件/连接在预览后变化时停止。线上失败会明确说明本地与线上各自结果，不显示整体成功。此按钮不传数据库、模板、图片或宝塔配置。

## 区域域名和站点域名联动

- “区域管理”支持逗号分隔多个绑定域名，第一个是主域名。保存区域时，同一网站、同一语言的 `ay_site.domain` 随之更新，保留原来填写的 HTTP/HTTPS 协议。
- “站点与公司信息”的域名是单个主域名。这里仍遵循原有草稿流程：先保存，再“同步到本地 PB”（线上管理后台叫“同步到 PB”）。同步时一起更新 `ay_area.domain`，替换第一个域名并保留 www 等别名；选择已有别名会将它移到第一位。
- 清空区域绑定或同步空的站点域名，会清空该语言两处域名。其他语言和其他网站不变。重复绑定到另一种语言时整次操作停止。
- 如果区域修改后仍有旧的站点资料草稿，页面会提示 PB 资料变化。先核对并重新读取，再编辑，旧窗口不能静默覆盖新域名。保存草稿本身不修改已生效的网站数据。
- “同步区域配置到线上”也会联动更新线上的站点主域名；“站点与公司信息 → 同步到线上”会反向联动线上区域绑定。仍需显式点击同步，修改本地不会自动发布。
- 没有站点资料记录的语言，在站点信息页会从区域绑定读取主域名；首次同步完整站点资料时创建记录，不凭空复制其他语言内容。

联动沿用现有 SQLite 表结构，无数据库迁移。测试使用隔离的测试数据库，验证双向更新、别名保留、空值清除、跨语言/跨网站隔离、旧版本冲突、线上事务回滚及原有资料流程。未为测试更改真实网站的域名数据。

# 系统授权码

Vue 后台「系统管理 → 站点管理 → 系统授权码」显示当前站点 PB 授权码，以及本地 phpStudy、线上宝塔两套域名与授权配置。授权码默认遮挡，可点击查看。

- 当前环境由站点记录的 `environment` 决定，域名来自 `publicBaseUrl`。请按实际环境配置站点。
- 当前 PB 授权码直接读取该站点数据库 `ay_config` 的 `sn`、`sn_user`。线上安装读取线上自己的 PB，不把本地授权码作为线上默认值。
- 线上域名初始候选来自 PB 语言区域的域名，可手工调整；这些候选不代表已经验证的授权关系。
- 「保存配置」只保存本环境管理后台中的独立配置，不更改 PB，也不连接另一台服务器。
- 「保存并写入当前 PB」仅允许当前站点环境，更新已有 `sn`、`sn_user`、`licensecode` 值，并清理 PB 生成的配置缓存。授权码须由用户提供，系统不会生成或验证官方授权码。
- 本地「线上宝塔」卡片的「保存并同步线上授权码」使用当前站点的 FTPS 配置，更新线上 PB 的三个授权字段并回读校验。首次设置或授权变更时操作一次即可，日常代码发布无需更新数据库。
- 「保存配置」仍只保存记录；切换站点、加载页面、部署源码均不会自动套用授权码。同步失败会保留本地已填配置，并显示失败原因，可直接重试。

两套配置保存在 `managed-sites/<站点 code>/state/system-license.json`，按站点隔离，不改数据库结构。该文件包含授权信息，仅管理后台登录用户可通过接口访问。部署管理项目源码时必须保留目标环境的 `managed-sites`、环境文件及 PB 数据库，不能把本地配置覆盖到线上。

接口为 `GET/POST /sites/current/system-license`，使用现有登录鉴权和站点请求头，禁用响应缓存。保存校验站点 ID、配置版本和 PB 数据库版本；发生并发修改时重新读取后再保存。

线上同步要求：当前环境为 phpStudy、已保存该网站的 FTPS 连接、FTP 根目录是 PB 网站根目录、线上域名列表第一项具有有效 HTTPS 证书，线上 PHP 支持 PDO SQLite 与 OpenSSL。连接使用网站发布中选择的网卡。HTTPS 连接固定到配置的 FTP 主机，并验证网站证书，不跟随重定向；上传后先检查域名与 FTP 目录对应关系，再执行更新。

同步不会上传或下载整个数据库，也不改表结构、业务内容、本地授权、宝塔服务配置。临时 PHP 任务只含加密后的固定授权数据，不接受 SQL、文件路径或命令；密钥经验证证书的 HTTPS POST 传送，任务有效期三分钟，执行后删除，FTPS 再次检查清理。SQLite 事务只更新 `sn`、`sn_user`、`licensecode` 三个现有字段，提交后独立连接回读，清理 `runtime/config/*.php` 配置缓存。响应通过 HMAC 和数据摘要核验。若网络中断后结果不明，可重试相同值；清理失败会给出具体临时文件名。此校验确认数据写入一致，不替代 PbootCMS 官方授权有效性校验。

# 产品公共参数

## 在哪里填写

管理项目 → 产品管理 → 添加产品 / 编辑 → **产品参数**。

每个产品单独保存一份，与该产品的语言文案分开。修改一次，各语言预览使用同一份数值。不会按产品标题把不同型号或不同网站合并。

所有产品固定显示四个输入框，不需要选择类型、添加参数或切换语言重复填写。电脑端两列显示，手机端一列显示。

## 直接填写

以下数值是用户提供的示例，不是所有产品的默认值。请只给实际符合参数的型号填写。

| 项目 | 岩芯钻机示例 | 水井／工程钻机示例 |
| --- | --- | --- |
| 钻孔深度 | 800 m | 600 m |
| 取芯能力 | BQ 1000 / NQ 800 / HQ 500 | 留空 |
| 钻孔直径 | 不使用 | 140-400 mm |
| 发动机 | 按实际型号填写，例如 玉柴 110 kW | 按实际型号填写 |

英文岩芯参数：`Depth (m): 800`、`Core Capacity (m): BQ 1000 / NQ 800 / HQ 500`，发动机填写型号或功率。

英文水井参数：`Drilling Depth (m): 600`、`Drilling Diameter (mm): 140-400`，发动机填写型号或功率。

钻孔深度只填数字，单位固定为 m；取芯能力直接填写完整组合文本，单位固定为 m；直径可填单值或范围，单位固定为 mm。发动机直接填文本，例如 `玉柴 110 kW`。

不适用的参数留空，预览与报价不显示空值。取芯能力与钻孔直径可以同时填写，原来的模板类型不再限制哪些参数显示或同步。内置参数名支持中文、英文、西班牙语、法语、俄语、阿拉伯语、葡萄牙语、印尼语、土耳其语和越南语，参数值不交给 AI 翻译。

旧版本的 BQ/NQ/HQ 三项自动合成一个输入框，清空后不会重新带回旧值。原来名为“发动机”的自定义字段会沿用，不重复创建。回拖力及其单位不再显示或同步，历史数据保留。已有自定义数据与内部价格也保留。

## 管理产品字段

进入 **系统管理 → 产品字段管理**，操作只作用于顶部选中的网站。

- **读取 PB 字段**：读取已有模型字段。四项基础参数默认启用，其他字段默认停用；原有图片、视频、回拖力等字段显示为保护项。
- **新增字段**：填写名称，可选单位与排序；PB 字段名留空会自动生成。新增后该网站的所有产品显示对应输入框，不需要逐个产品添加。
- **编辑 / 停用**：可改名称、排序或启用状态，已有 PB 字段名不可修改。停用后不显示、不同步，原数据不清空。
- **删除**：仅允许删除没有产品数据的非基础项目字段。有数据的请停用。删除项目配置不会删除 PB 原字段或数据库列。
- **同步字段到 PB**：先备份，再注册启用的原生单行文本字段并更新字段说明与排序，不改产品值或网站模板。

配置保存在当前网站目录 `managed-sites/<站点标识>/state/product-fields.json`，历史配置备份在同站点的 `backups/product-fields/`。迁移时与该站点目录一同保留。

## 保存与报价

点击“保存修改”保存到管理项目，切换语言或使用一键翻译不需要重复填写。已有产品未设置公共参数时保持原样。

旧版内部参考价仍只存在管理数据库，不写入 PB 网站扩展字段。报价仍兼容已保存的价格，只有币种一致时才带入；币种不同仍需手动报价，不做汇率换算。已保存的报价单不被产品价格变动追溯修改。

报价参数包含公共参数和原详情中的技术表格。如果两处重复，请以公共参数为准并清理旧详情中的重复项。

## 同步到 PB 网站

保存后点击产品的“同步网站”，会同步当前站点中已经配置且内容完整的所有语言。同步前仍自动备份 PB 数据库。缺少译文或缺少对应产品栏目的语言会被跳过并明确提示，不会用中文覆盖外语产品。

参数完全使用 PbootCMS 原生的产品模型单行文本字段。第一次同步某个参数时，项目按照 PB 自带“模型字段新增”的结构注册；不会修改 PB 的 PHP 程序、表关系或网站模板。PB 各语言产品记录保存自己的参数值副本，管理项目仍只维护一份。

| 字段 | 内容 |
| --- | --- |
| `ext_drill_depth` | 钻孔深度数值，单位 m |
| `ext_core_capacity` | 取芯能力完整文本，例如 BQ 1000 / NQ 800 / HQ 500，单位 m |
| `ext_drill_diameter` | 钻孔直径数值或范围，单位 mm |
| 已有发动机字段，或 `ext_engine` | 发动机型号、功率等文本 |

如果网站需要显示这些参数，仍按普通 PB 模型字段的方式，在模板需要的位置调用。例如：

```html
钻孔深度：{content:ext_drill_depth} m
取芯能力：{content:ext_core_capacity} m
钻孔直径：{content:ext_drill_diameter} mm
```

发动机应使用“产品字段管理”中显示的实际 PB 字段名调用。项目不会自行修改任何网站模板，也不会把示例数值批量写进真实产品。已有自定义字段继续兼容；新表单由当前网站启用的字段生成。网站不依赖管理项目服务运行即可展示已同步参数。

从 PB 拉回中文内容时，已有项目参数优先保留；全站重建会尝试在当前网站、当前栏目内匹配原产品并保留参数。首次从 PB 导入可恢复标准技术参数和项目创建的自定义参数，但 PB 不保存内部价格，因此新电脑仍应迁移管理项目数据库以保留内部参考价。

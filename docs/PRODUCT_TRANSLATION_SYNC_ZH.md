# 产品翻译进度与栏目同步

## 产品列表

- “已全部翻译”：当前网站启用的所有外语版本内容完整。
- “部分未翻译”：已有部分内容，但仍有语言或字段缺失。
- “未翻译”：外语内容尚未填写。只有型号标题、空白语言记录不算完成。
- 进度中的 `9/9 种外语` 不包含中文。网站增加语言后会重新计算，不依赖手动标记。
- 悬停翻译进度可查看缺少的语言及字段；上方可以筛选未完成产品。

检查已保存的标题、详情，以及中文已填写的副标题、关键词、描述和轮播标题。此状态表示内容完整，不是自动判断译文质量；未保存的编辑草稿不计入。

## 一键同步到 PB

1. 点击产品列表右上角“一键同步到 PB”。
2. 选择中文产品栏目，自动包含其子栏目，与列表当前查看的语言无关。
3. 查看预检查结果，点击“同步全部语言”。

按当前网站配置遍历全部语言，包含印尼语、土耳其语、越南语。只发布已保存且内容完整的语言版本；缺失版本会明确列为跳过，不会用中文代替。可以同步部分已完成版本，不必等整个产品翻译齐全。

同步前检查目标 PB 栏目和 URL 冲突，发现阻塞项时整批不写入。执行前自动备份，按已有同步规则新增或更新产品，不删除 PB 其他产品；重复操作更新已有版本。公共参数、图片和视频沿用现有同步规则，不修改网站模板或 PB 核心代码。

原有“覆盖 PB 当前范围”和“全站从 PB 重建”仍保持原先行为，与新增的非删除式同步不同。

## 验证

后端：在 `backend` 运行 `npm test -- --runInBand product`。

浏览器回归：启动前端后运行 `node tools/verify-product-list.cjs`。需安装 Playwright，或把 `PLAYWRIGHT_MODULE` 指向已有 Playwright 模块。此脚本使用独立浏览器和模拟 API，不登录真实账号、不发布到 PB，截图存放在 `tmp/product-list-check`。

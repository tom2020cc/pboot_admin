# 域名上线检测

入口：本地「网站发布 → 域名上线检测」，或数据库页面顶部同名入口。点击「检测全部语言」，页面逐语言显示结果，刷新或重开可查看上次报告和检测时间。线上环境隐藏入口并拒绝发起检测。

前提：代码与配置同步中已保存宝塔连接、服务器公网 IP 与线上管理项目目录；当前站点已填写线上域名列表；线上管理项目包含 `deploy/database-actions.py`。站点按 `managed_sites.code` 对应，不按本地与线上的数字 ID 猜测。

检测内容：

- DNS：从服务器查询 A/AAAA 地址，核对是否包含配置的公网 IP；内网解析不发送首页请求。适用于直连部署，CDN 或特殊代理需单独核对源站。
- 宝塔/PB 绑定：核对该网站根目录对应的 Nginx 配置域名与 PB 区域语言绑定。读取的是磁盘配置，实际服务是否生效还需结合首页结果。
- HTTPS：连接配置的服务器 IP，以每个域名作为 SNI，验证证书域名、信任链和有效期。剩余不足 15 天显示提醒。即使 DNS 缺失，也能检查源站证书。
- PB 授权：使用匹配的 PHP 版本、`www` 身份生成该域名首页。明确授权错误显示失败，其它程序错误显示待确认。不会显示或生成授权码，不绕过授权检查。
- 模板：核对线上 `ay_site.theme` 及 `template/模板/html/index.html`。
- 首页：解析和证书通过后，以正常 HTTPS 地址 GET 首页，检查 HTTP 200 和 HTML。跳转单列为提醒，不将跳到其它语言当作成功。授权和首页是独立检查，避免 Nginx 404 隐藏真实授权错误。

「通过」仅代表本次检查点通过，不代表翻译、产品页、各地区网络或全部证书续期设置已验收。全部检查均通过才计入“全部通过”；失败、提醒和待确认均需复核。每次修复后重新检测。

实现：本地 `domain-check.js` 从当前 PB 获取语言，使用既有宝塔账号调用一次性诊断任务。Python 源码随任务传递，无须先部署新检测脚本。数据库连接为只读，不修改 DNS/Nginx/证书/授权/业务配置，不创建备份或重启网站。PHP 首页执行可能产生正常的网站缓存、会话；任务限制 180 秒并清理临时计划任务。检测与数据库维护、发布及巡检互斥。

报告经 Gzip/Base64 压缩传回，避免宝塔任务日志仅返回末尾 8 KiB 导致语言结果丢失；完整性校验后按站点保存在 `managed-sites/<code>/state/domain-check.json`，不包含授权码和密码，不参与站点配置同步。连接、域名列表或本地 PB 库变化时，上次报告标为历史结果。

验证：Python 测试覆盖缺解析独立检测、授权错误与未知区分、私网和未授权域名不访问；Node 测试覆盖当前站点校验、互斥、报告持久化与过期；隔离页面测试覆盖轮询、处理建议转义和线上隐藏。发布此功能的代码仍遵循本地验证后单独部署的流程。

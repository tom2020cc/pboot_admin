# 多网站端口与实例隔离

每一个 PbootCMS 网站必须保留自己独立的一份 `pboot_admin`，不要让多个网站共用同一个工具目录。

## 端口在哪里配置

双击根目录的 `01-config.cmd`，在配置页面分别设置：

- NestJS 后端端口
- Vue3 前端端口
- SEO 工具本地端口
- FTP 网页工具本地端口

保存后，SEO 和 FTP 的启动器会直接读取这里保存的端口。配置端口已经被其他程序占用时，启动器会自动查找后续可用端口，并在命令窗口中打印实际地址。

## 怎样确认没有打开错误项目

不要凭记忆手动输入 `localhost:5188`。请使用当前项目根目录中的：

- `05-start-seo-tool.cmd`
- `06-start-ftp-tool.cmd`

SEO 页面顶部会显示当前站点、实际端口、项目目录和数据库路径。路径不属于当前网站时，立即关闭该标签页，不要执行写数据库、生成 Key 或推送操作。

## 怎样关闭

SEO 和 FTP 启动后会在各自工具目录写入 `.runtime.json`，记录本项目的实际端口和 PID。

双击 `04-stop-ports.cmd` 时：

- 后端和前端按当前项目 `.env` 中的端口关闭；
- SEO 和 FTP 只按当前项目的 `.runtime.json` 关闭；
- 不再固定关闭 `5188/5189`，避免误伤其他网站项目。

`.runtime.json` 是临时运行记录，工具正常退出后会自动删除。

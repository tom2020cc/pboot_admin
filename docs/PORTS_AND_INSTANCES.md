# 集中版端口与实例

多网站共用同一套管理服务，不再为每个 PbootCMS 网站分配一组端口。

| 服务 | 默认端口 | 说明 |
|---|---:|---|
| 后端 API | 5108 | 单进程常驻，所有站点共用 |
| 管理前端 | 5278 | 顶部切换当前站点 |
| SEO 工具 | 5388 | 配置、Google 状态和 AI 修复断点按站隔离 |
| FTP 工具 | 5389 | FTP 凭据、基线、巡检历史和续传断点按站隔离 |

端口只属于管理系统，与业务网站数量无关。网站差异通过请求中的当前 `siteId` 和 `managed-sites/<站点标识>/` 配置目录区分。

修改系统端口时编辑 `backend/.env` 和前端环境变量，然后重新启动；新增网站只进入“站点管理”，不要再修改端口。

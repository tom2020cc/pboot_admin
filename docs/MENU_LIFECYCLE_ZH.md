# 中文主栏目与多语言关联

## 新增

1. 菜单管理中点击“添加菜单”，创建中文栏目。
2. 填写名称、URL，选择中文父栏目和内容类型。选择父级后继承其类型；顶级栏目自行选择。
3. 保存后立即出现在中文列表，编码自动分配，状态为“新增待同步”。
4. 点击“一键翻译栏目”，勾选目标语言。新译文通过 `sourceMenuId` 关联中文栏目，不依赖栏目编号差值或排序。
5. 点击“同步全部到网站”，按父级、中文来源顺序创建 PB 栏目。单行“同步网站”只处理该中文栏目及关联语言；父栏目尚未同步时会提示先同步父级。

栏目内容类型来自当前 PB 的 `ay_model`。新栏目沿用同类型父级模板或模型默认模板；已有 PB 栏目的模型、模板不修改。

## 修改与翻译

中文“编辑菜单”页右上角可使用“翻译当前栏目”：默认勾选其他已配置语言，可调整模型和语言范围。未保存时先确认保存；只翻译当前栏目的名称和 SEO，不包含子栏目、不修改兄弟栏目，也不自动同步 PB。成功的语言直接保存在本地，失败语言可单独重试。目标语言缺少父栏目时，先翻译父栏目，再处理当前栏目。

- 中文名称或 SEO 修改后，已有译文标记“待重新翻译”。
- 中文图片、显示状态、排序及父级调整会更新对应语言，已有译文和 URL 不会被中文覆盖。
- 旧记录只在父级关系与 URL 能唯一对应时识别来源，不按顺序猜测。读取列表不写回数据；实际编辑、翻译或同步时才保存关联。
- 来源无法确定的语言栏目显示“待确认中文来源”，进入编辑页选择同类型、同父级关系的中文栏目；已有固定来源不能随意改绑。
- 历史空编码栏目会显示“未绑定，请编辑保存”。用户保存时才分配编码，不自动修复旧记录。

## 删除

1. 在中文列表点击“删除”，预检本地及 PB 的子栏目和内容引用，包含其他语言与 PB 副栏目引用。
2. 预检通过后，确认弹窗显示关联栏目数量和语言。确认只标记“待删除”，PB 网站暂不变化。
3. 同步前可点击“撤销删除”。待删除栏目不参与翻译、内容范围选择。
4. 点击“同步网站”或“同步全部到网站”时再次预检；通过后才删除该关联组的 PB 和本地栏目记录，不删除图片、产品或新闻。

有子栏目或内容时先迁移内容、处理子栏目并同步，再删除父级。获取 PB 栏目不会恢复待删除记录，也不会覆盖尚待首次同步的新栏目。所有同步失败应检查提示后重试；检测到 PB 数据库同时有其他写入时会中止。

## 验证

- 后端：`cd backend` 后执行 `pnpm test --runInBand`。
- 页面：设置 `PLAYWRIGHT_MODULE` 指向可用的 Playwright 包，运行 `node tools/verify-menu-lifecycle.cjs`。
- 测试使用临时数据库和接口模拟，不调用真实翻译、不创建或删除现有网站栏目。

# 产品列表批量操作

入口：管理后台 -> 产品管理。此功能只在当前所选网站中执行，不跨网站合并产品。

## 选择产品

1. 先确认顶部网站，再选择语言、栏目、翻译状态、显示状态或输入标题 / ID。
2. 勾选左侧复选框。表头复选框选择当前页；翻页保留已勾选项。
3. “选择全部筛选结果”可跨页选择，单次上限 100 项。超过时先缩小筛选范围。
4. 修改筛选条件或刷新列表会清空选择。切换语言重新读取产品，防止旧请求结果覆盖新语言。
5. 工具栏持续显示已选数量，滚动长列表时保持可见。小屏可横向滚动表格。

## 状态、排序与栏目

| 操作 | 后台影响 | PB 网站影响 |
| --- | --- | --- |
| 显示 / 隐藏 | 修改所选产品的显示状态 | 另行同步后生效 |
| 置顶 / 取消置顶 | 修改所选产品的置顶状态 | 另行同步后生效 |
| 推荐 / 取消推荐 | 修改所选产品的推荐状态 | 另行同步后生效 |
| 保存排序 | 保存所有已修改排序值，范围 0-999999 | 另行同步后生效 |
| 移动栏目 | 移动产品到当前网站的中文主栏目 | 另行同步后更新对应语言栏目 |
| 复制产品 | 复制产品及全部译文，生成隐藏副本与独立 URL | 不自动发布 |

显示、置顶、推荐、排序和栏目属于产品级设置，所有语言共用，并非只修改当前语言文字。确认弹窗会再次标明网站、语言及产品。

历史产品未设置置顶 / 推荐时，数据库值为 null。同步已有 PB 内容时保留 PB 原状态，不因新增字段而清空旧站设置；手动设置后才按后台值更新。

复制使用原有图片路径，不复制、删除图片文件。副本先保持隐藏，编辑核对后再显示和同步。移动前若产品或有效译文缺少独立 URL，操作会被拒绝，先在编辑页补全，避免后续同步生成重复记录。

## 批量同步 PB

1. 选好产品，点击“同步 PB”。
2. 选择“当前语言”或“全部已翻译语言”。
3. 确认后逐个处理，不删除未选择的产品。
4. 缺少必要译文的语言会跳过，结果显示为部分完成。先完善译文再同步。

列表原有“同步网站”及“覆盖 PB 当前范围”继续保留。范围覆盖 / 全站重建与本次新增的“同步所选产品”不同，不要混用。

## 批量删除

默认仅删除后台所选产品及全部译文，PB 网站内容与图片文件保留。

需要同步删除网站内容时，明确勾选“同时删除 PB 网站对应产品（全部语言）”。输入所选数量后才能执行。删除不可撤销，没有自动备份，不要用真实产品做测试。

删除 PB 时严格匹配当前网站、语言、栏目、模型及产品 URL，缺少 URL 时才回退标题匹配。遇到多个匹配、其他后台产品引用同一 PB 内容、数据库并发修改或权限问题，该项停止并显示错误，不模糊删除。数据库替换保留原属主、属组和权限，避免再次造成 PHP 登录失败。

## 结果与停止

逐项显示成功、部分完成、失败或待核对，可停止剩余任务；正在执行的一项会先完成。请求超时 / 网络中断后不自动重试，尤其复制和删除，应刷新并核对结果再操作，以免重复副本或误判删除。

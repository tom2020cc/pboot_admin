# 2026-09-23 多语言网站检查与修复

范围：山博钻机的 en、es、fr、ar、pt、ru、id、vi、tr 九种语言；本地 PB 网站和宝塔线上 PB 网站。CN 模板和 CN 业务记录不在修改范围内。按用户要求保留 Instagram、TikTok、YouTube 图标及现有链接，账号链接由用户后续修改。

## 根因与修复

线上不同语言的栏目使用相同 filename。PB 的 `ParserModel::getSort()` 原先跨语言取第一条匹配记录，可能取到 CN 栏目；产品详情和单页也有同类查询。因此外语页头正常，但面包屑、分类名称和内容来自中文记录。

在本地与线上 `apps/home/model/ParserModel.php` 的栏目、内容和单页查询中，优先返回当前语言的匹配记录，保留明确编号和唯一语言前缀链接的兼容行为。未改变数据库结构或批量改写栏目 URL。

其他修复：

- 九种语言分页改为直接输出对应译文，补齐 id、vi、tr；CN 和共享分页模板未修改。重建工具已同步这一规则。
- 线上八种非英文语言缺少关于我们、联系我们单页，共 16 条。从本地相同语言、相同栏目补入缺失记录，并转换其中的内部栏目链接；没有整库覆盖。
- 修正 43 条外语产品正文中的中文残留或图片引用问题，以及英文联系页中的中文地址。
- 修正 CR1600I 图片扩展名大小写；移除 CR1200I 正文中引用不存在的第五张图片，保留其四张已有图片。
- 修正俄语站点标题与公司名称中的中文。
- 同步修正本地、线上管理项目中的 43 条产品翻译草稿，避免再次发布还原旧正文。本地俄语站点资料草稿仅修改上述两个字段；保留其他字段和 baseRevision 冲突保护。

线上更新的代码仅为 PB 查询模型及九个外语分页文件。未调整宝塔、Nginx、证书或环境配置，未整体替换管理项目数据库。管理数据库草稿修复在暂停对应写入服务后执行，完成后恢复服务并验证数据持久化。

## 后续维护

1. 栏目、详情和单页不能仅按不带语言条件的 URL 取第一条记录；保留当前语言优先规则。
2. Linux 图片路径区分大小写，上传后的文件名应与正文和轮播字段一致。
3. 模板重新生成前先更新翻译字典；使用预检命令检查，不要直接把 CN 栏目编号复制给其他语言。
4. 如站点资料提示 PB 已修改，先核对草稿，再使用“从 PB 读取当前语言”；该操作会替换该语言草稿，不应跳过原有冲突保护。
5. `tools/repair-language-content.py` 与 `tools/repair-language-drafts.py` 默认只预览。后者的 `--apply` 只能在管理数据库写入服务暂停时执行，不能在运行中的 SQL.js 数据库文件上直接改写。

只读复检工具：`tools/test-language-route-resolution.php`、`tools/verify-rebuilt-language-templates.cjs` 和 `tools/audit-language-pages.py`。线上审计脚本当前针对本项目的线上根目录及数据库路径，不是通用数据库发现工具。

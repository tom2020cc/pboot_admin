# 栏目翻译修复

菜单管理中的语言数量表示栏目条数，不代表已经翻译完成。

## 操作

1. 先保存中文栏目名称和 SEO。
2. 点击“一键翻译栏目”。在外语标签下打开时默认只勾选当前语言，也可以勾选多种语言。
3. 只修复印尼语、越南语、土耳其语时，勾选 Bahasa Indonesia、Tiếng Việt、Türkçe。
4. 确认后逐语言翻译，结果显示“已保存”或具体失败原因；失败可单独重试。
5. 检查译文后，再使用原来的“同步全部到网站”。翻译操作不会自动写入 PB。

## 保存规则

- 中文是唯一翻译源。翻译名称和非空 SEO 字段，图片沿用中文。
- 已有栏目 ID、绑定编码、URL、模型和模板不改。缺少的目标栏目沿用已有逻辑按中文层级创建。
- 中文残留、返回数组不完整、截断输出等会进入备用模型流程。整批越南语长文本没有任何声调/变音标记时，按疑似串成英文处理。
- 这些是明显异常检查，不是完整的语言鉴定或专业译文审校，短词和产品型号允许原样保留。
- 同一语言的名称与 SEO 全部得到结果后才开数据库事务保存；写入失败整种语言回滚。某种语言失败不会中止后续语言。
- API `POST /menus/translate-all` 可传 `targetAcodes: ["id", "vi", "tr"]`。省略时翻译当前站点全部非中文语言。响应分别返回 `results` 和 `failures`，不能只凭 HTTP 200 判定全部成功。
- 后端保留翻译前本地数据库备份，不修改 PB 的数据库结构或模板文件。

## 验证

后端：`npm test -- --runInBand menu`

浏览器：配置 `PLAYWRIGHT_MODULE` 后执行 `node tools/verify-menu-translations.cjs`。浏览器测试使用模拟 API，不扣费、不写网站数据。

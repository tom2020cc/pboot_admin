# 百度中文站主动提交

## 操作顺序

打开 SEO 检查 → 百度，按三个卡片操作：

1. **配置中文站**：从当前 PB 项目的 CN 区域域名读取目标。山博项目只使用 `https://cn.shanbo-rig.com/`。进入百度“资源提交 → 普通收录 → API 提交”，复制该站点的 Token 并保存。留空保存不会清除同域名的已有 Token。
2. **主动提交页面**：先用“提交首页测试”真实提交 1 条。接口确认接收后，再按每批 20、50 或 100 条提交。提交前会显示域名和本批数量。后台再次校验所有网址属于当前项目的 CN 清单。
3. **查看结果**：打开百度索引量页面查看。提交成功只表示百度接收，不代表收录。不要每天重复全量提交。

百度 Token 按验证站点保存，不能跨项目共享；其他项目需验证自己的中文站并配置对应 Token。配置时不自动重置百度侧密钥。

## 状态与错误

- 本工具记录“整批明确接收成功”的网址，后续自动跳过，新增网址进入待提交列表。
- 部分接收、平台错误、网络失败都不会被标记为整批成功。百度响应没有明确说明哪些网址成功时，不推测成功网址。
- 接口错误后，批量操作停止。先检查百度平台状态，再测试首页，确认接口恢复后继续。
- `site init fail` 是百度 API 的原始错误，表示接口返回站点初始化失败；仅凭此响应不能判断是否因新站、额度或平台内部状态引起。检查普通收录中的站点和权限，持续失败可向百度反馈。
- “停用推送”保留 Token 与历史记录，不删除百度平台数据。保存配置可恢复启用。
- 已提交网址内容发生更新，可在百度平台按需提交。不要通过清空本地记录来每日重复提交。

官方说明：[百度普通收录 API](https://ziyuan.baidu.com/college/courseinfo?id=267&page=2)。

## 实现与环境

- `tools/seo_publish_tool/baidu-api.js`：中文域名选择、严格网址校验、接口返回分类与密钥脱敏。
- 当前项目 SEO 配置中的 `baidu` 保存站点、Token 与启用状态。状态接口只返回配置状态，不返回 Token。
- `managed-sites/<项目>/seo/baidu-submissions.json` 保存提交记录，各项目隔离。不在代码部署中覆盖该状态文件。
- `auto-submit-baidu.js` 必须通过 `SEO_SITE_ID` 指定项目，调用同一接口，一次最多提交 100 条，不自动启动服务、不循环提交。在线服务要求登录时应使用页面操作。
- 本次只修改和重启本地 SEO 工具，没有部署宝塔代码。

## 2026-09-23 实测

- 在已登录的百度平台确认当前验证站点为 `https://cn.shanbo-rig.com/`，按该站点保存配置。
- 本地识别 78 个中文网址（包含首页），其他语言被排除。
- 页面按钮实际提交首页，百度返回 `HTTP 400`、`error: 400`、`site init fail`。未记为成功。
- 官方手动提交首页触发安全验证，用户完成验证后页面输入框已清空，但未捕获成功提示，数据反馈页也未显示可确认的成功记录；因此未记为提交成功。
- 安全验证后再次测试 API，仍返回相同错误。没有继续提交整批 78 条。
- 单元与服务测试覆盖域名隔离、去重、重复提交跳过、部分失败不误报、错误后停止批量、恢复测试、密钥不回传。相关定向测试通过。

# 站点与公司信息：本地同步到线上

只为「站点与公司信息」与「系统授权码」保留直接线上同步。产品、新闻、视频、单页和栏目仍使用原有功能。

本地管理后台打开「站点与公司信息」，选择语言后，在「同步到线上」下选择当前语言或全部语言。确认框显示站点、目标 HTTPS 域名和语言范围，未保存的所选语言资料会先保存为后台草稿。无需先写本地 PB，也不上传整个数据库。

- 对线上已配置的语言，更新 `ay_site` 与 `ay_company` 资料；缺少资料记录时自动新增。空字符串也是明确值，会清空线上对应字段，不保留旧值，不从中文或其它语言补值；全空的公司资料同样可以新增或覆盖。
- 站点域名和模板选择随当前/全部语言资料同步，包含空值。域名须属于当前站点授权配置中的线上域名列表（支持主机名或 HTTP(S) 根网址），不能带入本地开发域名；非空模板须在线上存在 `template/模板名/html/index.html`，同步资料不会上传模板文件。保留线上统计代码、授权码，以及产品、新闻等业务内容。
- Logo、微信二维码及尾部信息、其它信息中引用的本地图片会通过 FTPS 上传并验证 SHA-256。图片写入内容摘要命名的独立目录 `static/codex/site-information-online`，不覆盖原图片。HTTP(S) 外链保留原地址。
- 单张图片限 5 MB，一次限 20 MB / 100 张；超限请按语言分批处理。
- 本地后台和本地 PB 分别保存各自数据。成功提示只说明此次资料已通过线上回读校验，不代表以后线上内容始终未变化。线上管理后台若有旧草稿，可用「从 PB 读取当前语言」刷新，远程同步不会覆盖线上管理后台草稿库。

连接复用当前站点保存的 FTPS 配置及「系统授权码」卡片中的线上域名（不需要改授权码）。第一个域名须具有有效 HTTPS 证书，且与 FTPS 网站根目录对应。服务器需要 PHP PDO SQLite 和 OpenSSL。线上必须已配置相应语言区域；缺少站点或公司记录时自动新增，重复记录或缺少语言区域时整批回滚。域名和模板按所选语言的资料写入，任何语言的域名或模板校验失败都会整批回滚；新记录仅统计代码留空，不修改表结构。

新增接口：`POST /site-information/sync-online`，沿用登录鉴权、当前站点请求头、内容版本校验、同站点互斥；校验请求站点 ID 和线上连接版本。部署环境必须为 `APP_ENVIRONMENT=local` 且站点环境为 `phpstudy`。线上环境及未知环境不展示入口，后端也拒绝调用。系统授权码的远程按钮遵循同一环境限制；线上继续使用「同步到 PB」或「保存并写入当前 PB」。

传输复用授权同步的加密临时任务机制：FTPS 上传固定用途、三分钟有效的 PHP 任务，HTTPS 验证证书及域名与根目录的对应关系后传递任务密钥。任务不接受客户端 SQL、表名或文件路径。SQLite 事务只更新固定白名单字段，提交后独立连接回读、清理 PB 生成缓存，再返回经过 HMAC 校验的结果。任务执行后删除，FTPS 再确认清理。失败时不显示成功；若响应中断，结果可能已提交，可重试相同资料。已上传而尚未被引用的摘要图片可能保留，可后续使用同名文件，无需自动删除。

验证：后端站点资料与授权码测试、PHP 临时任务的事务回滚与保留字段测试、隔离浏览器的当前/全部语言及线上隐藏测试。测试不写入正式线上资料。常规管理项目发布仍保留各环境数据库、managed-sites 配置与环境文件。

排查：旧版曾过滤站点域名与模板，导致新建语言记录这两项为空。更新本地管理后台后，在“站点与公司信息 → 同步到线上 → 同步全部语言到线上”重同步即可补齐，无需覆盖整库。整库同步仍保留线上环境绑定，需要更新这两项时使用此资料同步入口。

# 报价单 PDF 与语言版本

## 入口与范围

- 后台导航「报价单生成」，路径 `/#/quotations`。每个网站独立读取产品、公司资料、报价记录和浏览器草稿。
- 旧报价仍然保留，不批量改写数据库；读取时补齐缺少的展示字段。未带 language 的旧资料按中文兼容。
- 此次不上传 GitHub，不改变 PB 产品、栏目或翻译数据。

## 操作步骤

1. 在当前网站进入报价单生成，选择「新建报价」或从「报价单列表」打开旧报价。
2. 在编辑区上方选择报价语言。空报价可以直接切换；已有产品的报价会先弹出确认，保存原稿，再创建独立语言版本。
3. 系统读取当前网站产品库中该语言的名称、栏目及参数表，不再在导出过程中把整份报价交给翻译模型。英文、法文、阿拉伯文等由网站已启用语言决定，总共支持十种语言。
4. 译文缺失、读取失败或编号获取失败时，原报价保留。先去产品管理完成目标语言翻译，再回来重试。部分译文缺少参数时，工作台显示核对提醒，可以在报价中手动补充。
5. 新版本采用新的报价编号，产品数量、单价、币种、运费、定金比例、客户资料、选中图片及备注原样保留。已知默认标题和条款按语言切换；自定义商务条款不自动翻译，必须人工核对。修改过的产品参数只保留在原报价，新语言参数重新读取产品库。
6. 按「保存报价单」保存新版本。列表可以按语言筛选，保存后继续编辑不会变回中文。切换语言不等于汇率换算，币种与数字均不会换算。

## PDF 与网页

- 编辑区、预览区支持「编辑与预览」「编辑」「预览」，桌面双列占满可用宽度，手机上下排列。
- 文档恢复为 A4 横版的经典报价样式：左侧产品图片，中间技术参数，右侧数量、单价和总价，三栏并排。中文及外语报价均保持这个位置关系；阿拉伯文参数仍按从右向左阅读。
- 超高内容自动续页。参数使用真正的表格，续页重复表头，保留全部导入参数，不截断为 80 条。产品资料 PDF 仍使用原有 A4 竖版，不随报价样式改变。
- 数量、单价、行小计、设备总价、运费、定金、尾款及报价总额单独排版。报价数字不由 AI 生成或翻译。
- 新增产品默认选产品大图，没有大图时选第一张产品图，不默认添加缩略图。每个产品最多三张，可取消、重新选择、调整产品顺序。
- 预览与产品 PDF 共用图片加载队列、一次自动重试、150 秒总超时和重新排版。坏图会明确报错，不将缺图文件误报为成功。
- 「打开网页」「下载 HTML」先内嵌图片并完成分页；「导出 PDF」将分页文档提交当前服务器的 Chromium 生成可下载 PDF，不再打开电脑打印窗口。
- 共用认证接口 `POST /brochures/export-pdf`，无需额外第三方 PDF 服务、Key 或费用。接口路径保留现有兼容；服务器保持沙箱、图片内嵌、网络拦截和并发限制。
- 建议每份不超过 20 个产品；图片单张小于 10MB、整份图片小于 40MB，分页最多 150 页。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 某种语言不可选 | 检查当前网站启用语言，不使用其他网站的产品或栏目。 |
| 提示缺少译文 | 在产品管理补齐该语言名称和正文；报价切换不会用中文静默代替外文。 |
| 外语中仍有中文 | 核对自定义公司信息、商务条款和产品原有译文，系统会提示但不擅自删除。 |
| 图片加载失败 | 检查当前站点图片代理返回及图片格式，然后点重新排版。 |
| PDF 413 / 502 / 504 | 检查反向代理上传大小、读取超时、API 与 Chromium 日志；不要关闭登录或沙箱保护。 |
| 预览正常但导出失败 | 检查服务器字体与 Chromium 沙箱，先重试小份报价，不回退到电脑打印掩盖问题。 |
| 保存请求超时 | 先查报价单列表确认是否保存成功，再重试，避免重复创建。 |
| 浏览器缓存异常 | 原缓存保留，不自动删除。明确新建报价或从列表打开已保存资料后恢复编辑。 |

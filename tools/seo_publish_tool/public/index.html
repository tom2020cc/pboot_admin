Google Indexing 一键提交

用 Google Indexing API 真正把 URL 提交给 Google（只需配置一次服务账号）。配好后每条 URL 可一键提交，并查询 Google 的处理状态。普通页面属于“通知 Google 来抓取”，不保证一定收录——这是 Google 的规则，任何工具都一样。

Google 服务账号 JSON 怎么获取？点开看详细步骤（首次配置约 10 分钟，只需做一次）
  1. 用拥有本网站 Search Console 权限的 Google 账号，打开 Google Cloud Console（console.cloud.google.com）。
  2. 点页面顶部的项目选择器 →「新建项目」，名称随意（例如 shanbo-search-console），创建后切换到该项目。
  3. 左侧菜单「API 和服务」→「库」→ 搜索 Indexing API → 打开它 → 点「启用」（Enable）。没有结算账号一般也能启用，提交量小在免费额度内。
  4. 左侧菜单「IAM 和管理」→「服务账号」→「创建服务账号」。名称随意（例如 shanbocc），角色可以不选，一路「完成」。
  5. 在服务账号列表中点进刚建的账号 →「密钥」标签页 →「添加密钥」→「创建新密钥」→ 类型选 JSON →「创建」。浏览器会自动下载一个 .json 文件，这就是服务账号 JSON。
  6. 打开 Search Console → 左下角「设置」→「用户和权限」→「添加用户」→ 粘贴 JSON 里 client_email 的值（形如 xxx@xxx.iam.gserviceaccount.com）→ 权限选「完整」。漏掉这步提交会报 403。
  7. 用记事本打开下载的 JSON 文件，全选、复制，粘贴到上方输入框，点「保存并验证服务账号」。看到「取得 Google 访问令牌」即配置成功。

Google 后续操作教程

普通新闻和产品页没有可用的 Google 强制收录接口，以下步骤需要在 Search Console 官方页面完成。

首次部署或更换域名

  1. 点击“一键准备 Google 提交”，等待 FTP 和线上检查全部完成。
  2. 打开 Sitemaps 页面，提交页面中显示的 sitemap 地址。
  3. 等待 Google 处理；显示“成功”只代表 sitemap 可读取，不等于全部收录。

发布重要新闻或产品后

  1. 先更新 sitemap 并上传到线上。
  2. 复制该页面真实 URL，打开“网址检查”。
  3. 运行线上测试，页面正常后点击“请求编入索引”。

日常检查重点

  • 网页索引：查看未编入索引原因和趋势。
  • Sitemaps：确认最后读取时间与状态。
  • 设置中的抓取统计信息：确认 Googlebot 能稳定访问。

不能自动化的边界

  • 工具不能承诺排名，也不能保证每个 URL 被收录。
  • IndexNow 面向 Bing 等支持方，不会把普通页面提交给 Google。
  • Google Indexing API 不适用于普通新闻和产品页面。

换站部署清单

每个 PbootCMS 网站使用自己独立的一份工具目录和配置，互不共用数据库、端口、FTP 或 IndexNow Key。

1. 独立放置

  • 把完整工具目录复制到新网站自己的根目录。
  • 不要直接共用另一个站点正在运行的工具目录。

2. 项目配置

  • 在项目配置页填写新网站根目录、SQLite 数据库、独立端口。
  • 填写本地测试地址和真实线上地址。

3. 发布配置

  • 在 FTP 页面填写该网站自己的 FTP 信息。
  • 为该网站单独生成 IndexNow Key，禁止跨站复用旧配置。

4. 上线验证

  • 生成并上传 SEO 文件后检查线上 sitemap 与 robots。
  • 到对应站点的 Search Console 提交 sitemap。

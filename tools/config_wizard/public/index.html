6. 新电脑三步启动

安装依赖
安装 Node.js LTS 后，双击根目录的 00-install.cmd。
配置本站
双击 01-config.cmd，确认自动识别的网站根目录和数据库，保存。
启动项目
双击 07-start-all.cmd，保持后端终端打开；前端、SEO 和 FTP 会在后台运行。

完整教程见根目录 README_FIRST.md 和 docs/NEW_PC_SETUP_ZH.md。

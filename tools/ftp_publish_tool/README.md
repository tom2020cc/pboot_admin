# 网站同步 / 宝塔同步与安全巡检

这个工具独立于 Vue3/NestJS 前后端，负责网站同步到网上（原 FTP 发布）、项目级宝塔同步（`sync.html`）、覆盖前备份和远端异常文件巡检。两个同步页面均仅本地环境显示。

默认上传：

- `data/*.db`
- `static/`
- `uploads/`
- `sitemap.xml`
- `robots.txt`
- 根目录 `*.txt`，用于 IndexNow key

默认会排除：

- `data/*.before_*.db`
- `data/*.bad_*.db`
- `data/*.old*.db`
- `data/*.bak*.db`
- 所有 `.zip`、`.rar`、`.7z`

默认不上传：

- PbootCMS 程序文件
- 模板文件
- 前后端项目
- 日志、压缩包、缓存

## 第一次使用

日常请用项目根目录的 `start.cmd` 启动。工具默认端口 5189；项目约定通过环境变量 `FTP_TOOL_PORT=5389`（见 `backend/.env`）。

1. 双击项目根目录 `start.cmd`。
2. 浏览器打开网站同步页 `http://localhost:5389/`。
3. 同步到宝塔站点：直接点「一键填入宝塔目标」（自动填账号密码）；或手工填写任意 FTP 信息并保存。
4. 先点“刷新上传计划”，确认文件数量和路径没问题。
5. 点“测试 FTP 连接”。
6. 确认“覆盖前下载备份”已启用，再点“开始发布”。
7. 打开独立安全页 `http://localhost:5389/security.html`，网站确认正常后建立一次可信基线，后续扫描即可识别新增、篡改和消失的敏感文件。

命令行方式仍然保留：

- `npm run dry-run`（先演练不上传）
- `npm run upload`（按配置上传）

## 配置说明

```json
{
  "host": "你的FTP地址",
  "port": 21,
  "user": "FTP用户名",
  "password": "FTP密码",
  "secure": false,
  "remoteRoot": "/",
  "localRoot": "..",
  "backupBeforeOverwrite": true,
  "backupMaxFileSizeMb": 20,
  "securityMonitorEnabled": false,
  "securityIntervalMinutes": 360
}
```

`remoteRoot` 是线上空间的网站根目录。有些空间是 `/`，有些是 `/wwwroot`、`/public_html`、`/htdocs`。

如果不确定，先用 FTP 软件看一下远程目录结构：能看到 `data`、`static`、`template` 等目录的那个位置，就是网站根目录。

如果页面提示 `550 Failed to change directory`，通常是远程根目录不对。虚拟主机常见填法：

- `/`：登录后就是网站根目录。
- `wwwroot`
- `public_html`
- `htdocs`

新版网页工具会尽量使用相对路径上传，兼容不允许 `/data` 这种绝对路径的 FTP 空间。

## 发布保护

- 开启 `backupBeforeOverwrite` 后，工具会在覆盖远端同名文件前下载本机备份。
- 备份保存在 `backups/ftp-overwrite/<时间>/`，不会再次加入上传计划。
- 超过 `backupMaxFileSizeMb` 的单个远端文件默认不备份，发布日志会记录跳过原因。
- 发布与安全扫描不能同时运行，避免同一连接期间读取到半更新状态。

## 上传速度

数据库文件每次都会上传。图片默认开启 `skipSameSizeAssets`，如果线上同路径文件大小一致，就自动跳过，只上传新增或变化的图片。

如果你想强制全量上传图片，把 `ftp.config.json` 里的这一项改成：

```json
"skipSameSizeAssets": false
```

## 安全巡检

安全巡检只读取远端目录和文件，不会自动删除、改名或隔离线上文件。当前会检查：

- 可信基线建立后的新增、修改和消失文件。
- `uploads`、`static`、`images`、`cache` 等目录中的可执行脚本。
- 图片双扩展伪装、静态文件夹带 PHP、危险 `.htaccess`/`.user.ini` 配置。
- 动态执行、请求参数执行、压缩或长编码载荷等高风险代码组合。
- 线上敏感代码与本地同路径文件不一致，以及线上独有脚本。

首次无基线时会自动执行完整巡检。普通 JPG、PNG、GIF、WebP 图片只记录路径、大小和修改时间，避免通过 FTP 逐张下载；代码、配置、文本、无扩展名和可疑文件仍会下载计算哈希。确认结果干净后，可直接把本次结果设为可信基线；之后默认使用“增量快检”：仍会快速遍历远端目录以发现新路径，但只下载并深查新增、修改、哈希缺失和时间异常文件，未变化文件直接跳过。新增或元数据变化的普通图片也会下载检查夹带代码。定时巡检默认每 7 天执行一次代码和文本完整哈希复核。

扫描每完成一批文件会保存本地断点。关闭网页不会中断后台任务；网络失败、暂停扫描、后端或电脑重启后，可在安全巡检页点击“继续上次巡检”。恢复时会重新读取远端目录，并复用大小和修改时间仍一致的已完成结果，因此不会重复下载已检查文件。断点仅保存在本机，不会上传到 Git。

扫描较大的空间时可以随时点击“取消扫描”。取消会在当前 FTP 读取结束后关闭连接，不会改动远端文件。“完整复核”会读取更多小型文本和代码文件，速度慢于增量快检，但能抵御只依赖时间和大小造成的漏报。

发现异常后可以把选中文件下载到 `security-evidence/`，同时生成 SHA-256 留证清单。工具不会自动处置，确认来源后再用主机面板或可靠备份恢复。

建立可信基线前要先确认网站处于干净状态。扫描发现高风险项时，工具默认阻止更新基线，避免把异常状态误认为正常。

## 挂马预防

1. 空间商支持时优先使用 FTPS，并定期更换独立的 FTP 密码。
2. 点击“生成上传目录防执行规则”可在本地 `static`、`uploads` 等目录创建 Apache/IIS 规则，已有文件不会覆盖。
3. Nginx 不读取 `.htaccess`，需要在服务器配置中单独禁止上传目录执行 PHP、PHTML、PHAR 等脚本。
4. 定期启用远端巡检，并保留数据库、模板和发布覆盖备份。

## 两个同步页面（仅本地环境，互不干扰）

本地环境（`backend/.env` 的 `APP_ENVIRONMENT=local`）可见；宝塔线上环境隐藏入口（首页跳转安全巡检），同步接口返回 403。

**网站同步**（首页 `/`，原「FTP 发布」）：把当前站点数据发布到线上——`data/*.db`、`static/`、`uploads/`，或整站/仅 SEO 文件。目标存在每站 `ftp.config.json`；同步到宝塔站点时点「一键填入宝塔目标」直接复用宝塔同步配置里的站点账号（含密码）。

**宝塔同步**（`/sync.html`）：管理项目本身 → 宝塔项目目录（`sync.config.json`），三个预设：

1. **项目功能（代码）**：按发布审计规则过滤后增量上传源码；`.env`、密钥、数据库、node_modules 永不上传。上传后需在宝塔端手动构建并重启 PM2（页面提供可复制清单）。
2. **项目数据与配置**：按站点勾选 `managed-sites` 各节（site.json / seo / ftp / google / state / 上传图片），JSON 配置自动做本地→服务器路径改写，密码与密钥原样保留（建议 FTPS）。
3. **管理数据库（仅暂存）**：上传到服务器 `data/sync-staging/<时间戳>.sqlite` + sha256 校验单，绝不覆盖线上库；接管按清单手动执行。

详细步骤见 [docs/BAOTA_SYNC_ZH.md](../../docs/BAOTA_SYNC_ZH.md)。

同步目标保存在工具目录 `sync.config.json`（含 FTP 密码，已 git-ignore）；增量清单与远端备份在 `sync-state/`（同样 git-ignore）。两个页面的上传任务互斥，同一时间只运行一个。

## 本地使用提醒

这里会保存 FTP 密码，所以不要把 `ftp_publish_tool` 暴露给外部访问。

我已经加了 `.htaccess` 和 `web.config` 来尽量禁止 Web 访问，但如果你的线上服务器是 Nginx，可能不会读取这两个文件。最稳的方式是：本地使用这个工具，不要把 `ftp_publish_tool` 上传到线上空间。
